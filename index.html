WHAT RUNS WHERE?

One extension.
A local connection.

Augmentor Browser needs three parts. Having DSH installed is necessary, but it does not replace Augmentor’s companion.

  1. Chromium extensionThe sidebar and visible browser actions.
  2. Augmentor companionThe locally installed bridge between the extension and DSH.
  3. DeepSeek HarnessYour agent runtime, configured models and tools.

Does Browser work on every OS?

Chromium’s extension and native-messaging technology supports Linux, macOS and Windows. Augmentor still needs its companion installed and registered for the particular OS. We currently verify the complete Augmentor setup on Linux; macOS and Windows support is not yet verified.

Chrome’s native-companion requirements ↗

Can I install Desktop today?

Yes, from the prepared 0.2.9 bundle on Debian 13 amd64 with the supported DSH setup. Install both Debian packages for Desktop; the Chromium extension is optional. This is a preview with documented limits, not a stable release for every Linux distribution.

What remains for website visitors: publish the verified bundle as a public release and add its download link. Until then, the preview prompts require a bundle you already have.

BUILT AROUND YOUR AGENCY

Your model.
Your way of working.

Augmentation starts with you. A focused interface puts useful actions close at hand, without making the harness your whole workspace.

⌘

One shortcut away.

Choose your Desktop show/hide shortcut. Bring the agent into view, give it a task, and tuck it away again. Keep the compact activity view nearby when you want to follow progress.

◈

Local or cloud. Your choice.

Both editions use your configured DSH models. Run a local model through a compatible endpoint, such as llama.cpp, or choose a cloud provider. Switch models for the task.

⊙

Keep sovereignty practical.

Choose where inference runs. With a local model, prompts can stay on your machine; cloud models send requests to your chosen provider. Connected tools and websites have their own data flows.

▣

Browser + local computer tools.

The public Browser 0.1.32 preset goes beyond webpages: its DSH tools can run local commands, read and write files, and search your filesystem.

Access follows your OS permissions and DSH setup. The newer 0.2.9 Browser preset is browser-scoped; graphical desktop control is provided by the Desktop integration.
⌑

A library for your best prompts.

Save, search and reuse instructions. Bring a useful prompt back into the conversation instead of writing it from scratch each time.

✧

Improve the prompt before sending.

Use AI prompt improvement to turn a rough request into clearer instructions. Review the result and keep control of what you send.

◐

Make it feel like yours.

Change panel and accent colours, brightness, saturation and transparency. Choose light or dark, adjust formatting colours, and tune the visual effects.

</>

Code you can read and use.

Syntax-coloured code blocks separate code from conversation. Use the copy control to take a block into your editor without selecting it line by line.

⑂

Keep the conversation moving.

Return to history, copy a response, edit a request or branch a conversation. Keep working from the context you already built.
