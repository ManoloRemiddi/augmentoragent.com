Keep your workspace yours.

  1. Start with a working DSH profile and model.
  2. Download the versioned package and follow its guide.
  3. Finish active tasks, restart your existing DSH process and reload the web app.

A FEW USEFUL DETAILS

Before you get started.

Which DSH versions have been checked?

The published plugin checks target DSH 0.1.5-rc.1. They do not cover every plugin combination, provider or later DSH version. Read the dated collection checks and each plugin’s guide for its requirements. Adaptive Reasoning and Prompt Library are previews.

Do I need these for the complete Augmentor preview?

The complete installer already includes its required plugins and shared prompt library. Steering is included in the Augmentor Linux preset. Install standalone additions only when you need them for another setup. Keep the complete release’s matching Browser companion; do not substitute legacy Browser 0.1.32.

How are the projects licensed?

The standalone plugins and the original September 14 collection packages carry their own MIT licenses. Current Augmentor Desktop and Browser use MIT with Augmentor Resale Restriction: personal and business use and modifications are free; reselling Augmentor requires written permission. Earlier MIT releases retain their original terms.

Where do I report an issue?

For current Augmentor, use the active issue tracker. For a standalone plugin, use its source repository above. Report catalogue or collection problems in the collection repository. Include versions and reproduction steps using synthetic examples.
