Organisation v1.2.1

Metafolder

Turn a busy sidebar into an organised workspace. Group projects and sessions under named, coloured folders so related work stays together.

  • Drag workspaces and sessions into groups.
  • Choose colours and collapse groups you’re not using.

Groups change the sidebar view, not your files’ locations. They are saved in this browser; cross-device sync is not included.

Automatic reasoning v0.2.0Preview

Adaptive Reasoning

Let straightforward writing tasks use less thinking, while difficult or unfamiliar tasks retain more. Effort is selected for each request after one-time setup.

  • Fast paths for supplied-text rewrites and summaries.
  • Conservative rules keep high effort for uncertain tasks.
  • No extra classifier model or GPU keep-alive.

Setup is required for your preset and model. The stock package only acts on its tested Augmentor/Qwen route. This preview uses English task rules, and speed or quality gains are not guaranteed.

Reusable prompts v0.2.1Preview

Prompt Library

Keep useful instructions close at hand. Save, search and edit reusable prompts in DSH Settings, with a full preview before you make changes.

  • Give prompts memorable shortcut names.
  • Preserve your draft when an edit conflicts.
  • Use a standalone store or an existing Augmentor library.

Standalone mode needs Python 3 and starts with an empty library. Existing prompts are left intact. Slash-menu insertion requires a compatible Augmentor app.

Getting started

A few additions. Your existing harness.

01 / CHOOSE

Start with what you need.

Download one plugin or the collection. Every package comes with its own guide. You don’t need to install all five.

02 / SET UP

Follow the plugin’s guide.

Use your existing DSH web profile. Browser control needs an extension; the previews have their own setup requirements.

03 / USE

Restart when tasks are finished.

Restart your existing DSH process, reload the page and try the new feature. Keep your settings and model choices.

What do I need before installing?

A working DeepSeek Harness web profile and Node.js 22.19+ or 24+. These releases were checked with DSH 0.1.5-rc.1. Augmentor’s browser integration targets Linux and Chromium. Prompt Library’s standalone store also needs Python 3 with SQLite support. Check each guide before using a different setup.

Does the collection install everything at once?

No. The ZIP contains five original release packages, a getting-started guide and file checksums. You choose which plugins to install. The packages were checked individually; every possible combination has not been tested together. Open the collection guide.

What does “Preview” mean?

Adaptive Reasoning and the standalone Prompt Library are early releases with documented limits. Adaptive Reasoning needs model-specific setup. Prompt Library’s new standalone storage has automated tests but has not had a full native-browser end-to-end test in this release audit. You can leave either preview out of your installation.

Are the plugins free? Do I need a DeepSeek model?

All five plugins are free and open source under the MIT license. They extend DeepSeek Harness; they do not require you to choose a DeepSeek model. Your model provider’s normal costs still apply. Adaptive Reasoning only works on routes whose effort controls you have configured and verified.

How do I update, uninstall or get help?

Each setup guide includes upgrade and removal instructions. Existing linked installations should be updated in place without duplicate entries. This collection is dated 13 September 2026; check the individual GitHub releases for later versions. Report problems in the relevant repository, using a synthetic example rather than private prompts or credentials.
