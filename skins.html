Install your skin
  1. Download the .augmentor-skin.json file.
  2. In Augmentor Desktop, open Colors & skins.
  3. Choose Import… and select the file. Rename it if that name already exists.

For Augmentor Desktop with skin import (the 0.2.9 preview supports images). Your chat, model and credentials are unchanged. An uploaded image is included in the skin file, so share the file only if you want to share that image too.
