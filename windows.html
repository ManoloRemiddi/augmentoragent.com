Augmentor Agent for Windows

Version 0.2.13 · Handy dictation preview 3 · Windows 11 25H2 or later · x64 and ARM64

This preview includes built-in Handy dictation. Physical PC testing starts with this download. It includes Desktop, the matching Browser extension, DSH and the required private runtimes. Your model account, API key and model weights are not included.

Before installing: this preview is unsigned. Windows may warn about an unknown publisher or block it under Smart App Control or your organisation’s policy. Automatic updates are not available yet. Read the security notice and preview limits.

Choose your download

Open Settings → System → About. Under System type, choose the Intel / AMD download for an x64 processor, or Windows on ARM for an ARM processor. Under Windows specifications, check that you have Windows 11 version 25H2 or later (OS build 26200 or later).

Windows 10 and Windows 11 24H2 are not supported by this installer. RTX Spark hardware has not been tested; an ARM64 build does not establish compatibility with a specific machine.

Install and connect

  1. Open the matching installer as your normal Windows user. It installs the app and bundled Python, Node, PowerShell, DSH and required plugins. No separate developer tools are needed. Login startup is optional.
  2. Leave Open Augmentor selected at the end. Afterwards use the single Augmentor Agent entry in the Start menu.
  3. Open the three-dot menu → Agent setup → Install and start DSH. Then choose Add or change model and enter your provider, API key and model, or compatible model server connection. Use your own credentials; provider usage may have a cost.
  4. Send a short message. Confirm you receive an answer, then close and reopen Augmentor to check your conversation remains.
  5. For Browser, open Browser setup and select the installed Chromium-based browser you want to use. You can browse to its .exe; there is no fixed brand list. Setup opens the extension page and supplies a folder path. Enable Developer mode, choose Load unpacked, paste or select the supplied extension folder, and pin the extension. Use the matching bundled extension. Enterprise browser restrictions may prevent this step.
  6. Ctrl + Alt + Space shows or hides Augmentor. Ctrl + Alt + Shift + Space controls the second window. Change shortcuts in settings if another app uses them. Appearance → App size makes fonts, icons and the whole app larger or smaller.

Dictate into other applications

Open Settings → System dictation · Powered by Handy, turn it on, choose a transcription model and review its terms before downloading it. Hold Ctrl + Space while speaking and release to insert the transcription into the focused application. Escape or × cancels. You can change the shortcut or microphone and turn dictation off in the same settings. Its recording pill follows your Augmentor colours and animated circle. No separate Handy installation or tray is needed.

Windows security notice

Only download from this website or the official GitHub release. An unsigned installer can show “Windows protected your PC” or an unknown publisher message.

If SmartScreen offers More info → Run anyway, proceeding is your decision after verifying the source and checksum. If your Windows policy blocks it, wait for a signed release. Do not disable Defender, Smart App Control or organisational protections. See Microsoft’s Smart App Control guidance.

Optional: verify the download

Open PowerShell in Downloads and use the command matching your download. Compare the result with SHA256SUMS from this release.

Get-FileHash .\Augmentor-0.2.13-windows-x64-preview.exe -Algorithm SHA256

For ARM, replace x64 with arm64. Checksums detect changed downloads; they do not replace a trusted publisher signature.

Preview limits

Shared desktop, DSH setup/chat and the Chromium companion are the preview focus. Native x64 and ARM64 builds have automated Windows runner evidence; the exact development candidates have installation and recovery evidence. Your installation is the first physical PC acceptance stage. Every browser, model provider, security policy and graphics driver has not been qualified. Comet on Windows and RTX Spark hardware have not been physically tested.

Local voice and memory engine provisioning, desktop automation, Pi and Codex integration are not qualified for Windows. Handy dictation is bundled with its private WebView2 and native inference runtime; physical recording and typing acceptance remain to be checked on your PC. Shared controls being present does not establish that those features are ready here.

No automatic updates or cross-version manual upgrades yet. Do not install a different build over this preview, including preview 3 over preview 1 or preview 2. Future releases must supply a supported upgrade procedure. To repair this exact build, finish tasks, turn off System dictation in Settings, close Augmentor windows and browser work, then use Installed apps → Augmentor Agent → Modify or rerun this same installer. Preserve data if repair refuses.

Remove or report a problem

Finish active work, turn off System dictation in Settings and close Augmentor, then use Settings → Apps → Installed apps → Augmentor Agent → Uninstall. App removal retains conversations and settings.

Program files live under %LOCALAPPDATA%\Programs\Augmentor Agent. Personal data lives under %LOCALAPPDATA%\Augmentor. Do not manually delete personal data unless you intend to erase it. Repair and recovery copies also use disk space.

For feedback, include x64 or ARM64, Windows version/build, browser name, the exact visible message and whether setup or first launch failed. A screenshot can help. Keep API keys and private conversations out of public issues. Report an issue ↗
